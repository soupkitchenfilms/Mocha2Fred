# Changelog

## 0.1.0 (2026-11-23)

First public release.

- Fred Roto: a folder per Mocha layer with the layer's track keyed on the folder and the shapes keyed inside it
  (Fred 0.3.2 and newer); baked Roto for Fred 0.2.21 to 0.3.1.
- Fred Tracker, Transform and CornerPin at Fred 0.3.22's op versions, with version gates for older Fred releases.
- Fred PlanarTrack: the Mocha surface's corner track.
